\begin{abstract}
Intraweight injection lets one model change another model’s behaviour by editing its weights without gradients. IWIBench tests whether these changes persist without impairing other capabilities across ten task families covering lexical associations, response conventions, factual updates and response tendencies. We evaluate ten editor configurations on Gemma 3 4B IT, using the same thirty selected episodes for each. Editors have four tools, bounded tensor access and fixed budgets for generation and inspection. Their weight patches are evaluated in fresh processes with the inference code unchanged.

We find that while some configurations achieve substantial gains in alias acquisition and recoding, success varies by task. No configuration earned positive reward for structured-response defaults, and only 5.6-terra did so for answer-length control. Selective withholding was the only domain that improved with reasoning effort, reaching nine of nine targets at high effort. We conclude that success in one family gives little assurance of general editing ability. In addition, we reflect on some strategies that models have repeatedly resorted to, evidencing a common, recent and taught origin to this editing capability.
\end{abstract}
